# Example exports

Generated by `ExampleExportsTest` from **synthetic** data (simulated drives starting and ending at a Manteno, IL home point, sample expenses and payments) using MapLedger's real export code.

| File | Contents |
|---|---|
| `MapLedger-2026-mileage-log.csv` | IRS-style mileage log (one row per trip, 26 columns incl. odometer, purpose, coordinates, source, confidence, rate, deduction, audited adjustments). Note the Nov 9 trip: classified business but **not counted** because its home-travel review is still open. |
| `MapLedger-2026.xlsx` | Same log plus Expenses and Income sheets. |
| `MapLedger-2026-tracks.gpx` | GPS tracks of the live-recorded trips. |
| `MapLedger-data.json` | Full database export (same format as the encrypted backup's contents). |

The PDF export uses Android's `PdfDocument`, which can't run off-device, so no PDF example is included yet.
